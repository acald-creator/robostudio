01 Surfaces

The R−B figure is the 8-bit red-minus-blue channel spread — how much hue actually survives quantisation. Below about 8 a cast reads as neutral grey to most eyes, however it was authored.

@for (s of active().surfaces; track s.name) {
{{ s.name }} oklch({{ s.ch }}) {{ s.hex }} @if (active().neutral) { neutral by design } @else { R−B {{ s.rb }} }
}

All five sit below APCA's black clamp (Y < 0.022), so darkening the ground buys no contrast — only the text side can. And no gradients across adjacent surfaces in any palette — the steps are too close to band cleanly.

Wide gamut

accentsRGB CP3 CP3 ceiling
@for (p of p3; track p.name) {
{{ p.name }} {{ p.srgb }} {{ p.p3 }} {{ p.ceiling }}
}

If your display is P3, the swatches are already showing the lifted chroma — each clamped to its own hue's ceiling. accent-blue's sRGB value sits at 98% of its ceiling; it cannot go higher. Red is the lowest-luminance hue, so a dark "serious" red can never carry much contrast — errors should lean on the badge, not the hue.
